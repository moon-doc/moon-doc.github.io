## 🚀 快速开始

1. **配置 AI 模型**：设置 → AI 设置 → 模型（支持 DeepSeek / OpenAI / Ollama / 自定义端点）
2. **打开文档**：PDF / EPUB / Markdown 均可
3. **开始共读**：点阅读器工具栏「AI 对话」或首页「AI」导航，选中文本即问即答

未打开文档时对话会被拦截并提示；未配置 AI 时会引导打开设置。
