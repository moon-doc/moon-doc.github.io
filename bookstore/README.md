# 书城书源开关（服务端清单）

`sources.json` 是**小月亮阅读器书城的书源开关**：App 启动时与每次进入书城（缓存超过 5 分钟）都会拉一次，
据此决定哪个书源可用。

## 怎么改

在 GitHub 网页上直接编辑本目录的 `sources.json` → 提交 → Pages 重建约 20 秒 → App 下次进书城生效。
**不用发版**，也不用改 workflow。

- `"enabled": false`：停用该源。App 里这个源整个消失（不出芯片、不参与检索与推荐流、不计入分类表），
  后端也会拒绝它的检索与下载；该源的下载主机白名单同步收窄。
- `"note": "…"`（可选）：临时说明，覆写 App 里该源的一句话介绍（如「上游维护中」），用于告知用户。
- `"schema"` 必须为 `1`；整个文件是 JSON，**不要写注释**。

`id` 只能填 App 已内置的源（当前：`wenshuoge` / `gutenberg` / `wikisource` / `shuge`）。
写了 App 不认识的 id 会被忽略，不影响其余条目——旧版本 App 拿到新清单是常态。

## 安全阀

清单里列不全、写坏、schema 不认、或这一份根本拉不下来时，App **保留上一次生效的清单**；
从未取到过就按「全部启用」跑（即编译期默认值）。所以删条目 = 恢复默认，而不是把源关掉。

本域（`moon.jdk.plus`）是 App 的平台级分发主机：即使把**所有**书源都停用，清单本身仍可被拉取，
开关随时能撤回。
